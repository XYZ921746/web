与伊蕾娜一起旅行的故事

ElainaChat-mod 是以 ElainaChat 开源版二次开发的客户端，为伊蕾娜的旅行提供了更多的可能 —— 感兴趣的话，可以去原项目网页看看。 本项目新增加了 Agent 功能，插件可拆装，根据你的需要进行不同的搭配！

项目亮点

本项目在原版项目的基础上进行的改进。

mod 自定义功能

想给项目加点功能，不用碰主程序 —— 用项目内提供的 插件开发 skill 写一个 mod 就行： 一个目录加一份清单，装、卸、开关都在设置里。

对话优化

新增了模型思考强度的控制（部分模型或中转可能有兼容问题），以及新开的 第三人称转述模式，让对话更加自然。

定时任务

通过定时任务，你和伊蕾娜做过的约定将会实现 —— 比如 7 点准时和你说早安，或者 30 分钟后提醒你喝水。

Agent 能力

通过这个功能，电脑上可以陪你工作 —— 它知道你正在干什么，你愿意的话甚至可以让 AI 帮你干活； 手机端可以查看手机消息、操作手机（点击 / 滑动 / 输入 / 截图 / 读通知），全程不经过作者云端。 偶尔还会吃你的醋。

电脑版 / 安卓版

聊天与界面两端同构，但「能操作什么」是互补的。

电脑版（Web）

  • 克隆仓库，双击 启动.bat（零依赖、零构建，需 Node.js ≥ 20）
  • 浏览器打开 http://127.0.0.1:4173
  • Agent 可读写电脑文件、执行本机命令

安卓版（APK）

  • 到 Releases 下载 lite-debug.apk（约 10.8 MB）
  • 允许「安装未知来源应用」后安装
  • Agent 可操作手机：点击 / 滑动 / 输入 / 截图 / 读通知

APK 是「纯净版」——只含程序本体，不含任何插件与图片资源；那些按需下载并在应用内安装。
