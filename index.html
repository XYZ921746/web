04常见问题

旅人常问

关于安装、数据和隐私，先把常见的问题替你问完。还有别的，可以到 项目仓库提 issue。

「自带 API Key」是什么意思？

程序没有作者的中转网关。你在设置里填入自己的模型服务商 API Key，请求由你的设备直接发往服务商，费用与额度也归你的账户。

Agent 会上传我电脑或手机里的文件吗？

Agent 的操作在你的设备上完成，全程不经过作者云端。电脑版可以读写文件、执行本机命令；手机版可以点击、滑动、输入、截图、读通知，也能读写你授权的手机文件。具体能看到什么，取决于你交办的任务 —— 建议只在信任的环境里使用。

APK 里都包含什么？

它是纯净版：只含程序本体，不含任何插件与图片资源。立绘、场景、Live2D 引擎和模型都按需下载，装进应用后再启用。

电脑版和手机版有什么不同？

聊天、主题、插件与数据备份在两端同构；区别主要在 Agent：电脑能读写文件、执行命令，手机能操作手机界面、读写授权文件，各自做擅长的事。电脑版需要 Node.js ≥ 20，零构建启动。

电脑和手机的数据怎么同步？

数据分类落盘保存，电脑版与安卓版可以互相导入备份；也可以手动导出标准 zip，手机端会导出到文档目录。

插件与素材可以商用吗？

程序与插件代码以 GPLv3 发布；角色立绘、场景背景、Live2D 模型等素材的权利属于各自作者，商用需另行取得授权。插件商店与模型区的每张卡片都标注了用途，安装前看一眼。

遇到问题，或者想投稿怎么办？

可以到 web 仓库提 issue，或加入作者群聊。插件与模型都有各自的 GitHub 投稿表单：插件投稿、模型投稿，不用会 git。
