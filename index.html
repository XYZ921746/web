01 / AGENT

Agent 能力：电脑与手机，都是她的工具箱

电脑上，她能读写文件、执行本机命令，还能真开一个浏览器窗口看页面、点按钮、填表单；手机上，她能点击、滑动、输入、截图、读通知，也能读写你授权的文件。需要「现在的事实」时，她自己上网搜。所有操作都发生在你的设备上，不经过作者云端。

04安全与数据

旅途的行李，只放在你手里

数据不出你的设备，能力开多少由你决定 —— 这是整个项目的前提，不是附加项。

数据全在本机

聊天记录、人设、记忆、API Key 全部存在本地，不进仓库、不上传作者服务器。

访问密码 + HTTPS

局域网设备接入需要访问密码，带强度校验与防爆破；本机 HTTPS 自签证书开箱即用。

AI 权限四档

关闭 / 逐条确认 / 自动通过（禁止删除）/ 完全访问，一档管电脑与手机两侧。

备份与局域网共享

导出标准 zip（数据 + 插件 + 技能）；同一局域网的两台设备能直接互相拉取备份。

日志脱敏

应用内按级别与模块查看、导出日志；敏感字段（含各类 Key）落盘前自动脱敏。

更新只提示不替换

应用内查看最新发布与更新说明，按当前形态给出对应安装包；装不装、什么时候装，由你决定。

05常见问题

旅人常问

关于安装、数据和隐私，先把常见的问题替你问完。还有别的，可以到 项目仓库提 issue。

「自带 API Key」是什么意思？

程序没有作者的中转网关。你在设置里填入自己的模型服务商 API Key，请求由你的设备直接发往服务商，费用与额度也归你的账户。支持 OpenAI 兼容、Anthropic、OpenAI Responses 三种协议，可自填 Base URL。

Agent 会上传我电脑或手机里的文件吗？

Agent 的操作在你的设备上完成，全程不经过作者云端。电脑版可以读写文件、执行命令、开浏览器；手机版可以点击、滑动、输入、截图、读通知，也能读写你授权的文件。权限有四档，具体能看到什么，取决于你交办的任务 —— 建议只在信任的环境里使用。

电脑版要装什么环境吗？

下载安装包（或解压便携版）直接用，不需要装 Node.js，也没有构建步骤；外壳依赖系统自带的 WebView2 运行时，一般 Windows 10/11 都有。只有「从源码运行」才需要 Node.js。

APK 里都包含什么？

它是纯净版：只含程序本体，不含任何插件与图片资源。立绘、场景、Live2D 引擎和模型都按需在应用内下载安装。

电脑和手机的数据怎么同步？

两种方式：导出标准 zip（数据 + 插件 + 技能）互相导入；或者同一局域网内直接开启共享，用地址与访问密码互相拉取，不必先拷文件。

插件坏了会弄坏我的应用吗？

不会。插件默认关闭；装坏的插件会被自动停用并写盘记住，下次启动不再重试，原因只显示在那张插件卡片上，不弹全局弹窗、不影响其它插件与宿主。

插件与素材可以商用吗？

程序与插件代码以 GPLv3 发布；角色立绘、场景背景、Live2D 模型等素材的权利属于各自作者，商用需另行取得授权。插件商店与模型区的每张卡片都标注了用途，安装前看一眼。

遇到问题，或者想投稿怎么办？

可以到 项目仓库提 issue，或加入作者群聊。插件与模型都有各自的 GitHub 投稿表单：插件投稿、模型投稿，不用会 git。
