把你的模型放上来

第三方作者也能投稿 —— 走 GitHub 表单，不用会 git；审核通过后作为 web 仓库的 Release 资源上架，并登记进模型区。

打开投稿表单 回模型区

怎么投稿

三步：填表单 → 维护者把 zip 传到 Release → 登记进模型区。模型文件不用经过你以外的任何人。

① 填投稿表单

  • 点上面的按钮打开 GitHub 投稿表单（需要一个 GitHub 账号）
  • 填模型名、作者、授权方式，以及模型 zip 的下载地址
  • 模型动辄几 MB，别直接贴在 issue 里：先传到自己的网盘或 Release，贴链接就行

② 模型怎么打包

  • zip 的根目录就是模型名那一层（解压出来是「模型名/…」，不是一堆散文件）
  • 必须含 .model3.json + .moc3（Cubism 3）与纹理图
  • 中文名、空格都支持；放一张 icon.png 就有缩略图，没有就显示名字首字

③ 为什么不能直接传文件

站点是 GitHub Pages 静态托管，没有服务端接收文件，所以做不了「网页里选个文件直接上传」。 要做到网页直传，得另起一个小后端（GitHub App / Worker 代提交），代价是多维护一个服务与一份凭据，暂不做。

投稿前请确认：你有权分发这个模型（自己做的，或已获原作者授权）。 模型素材的著作权属于各自作者，上架时会一并标注你的署名与授权方式。
