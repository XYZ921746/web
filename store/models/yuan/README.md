以下条款整理自原作者发布的视频与说明，**以原作者的最新说明为准**：

- **需关注作者**：使用前需关注作者；取关后自动失去使用权。
- **公会不可使用**：公会场景明确禁止使用。

## 随手记

- zip 的**根目录就是模型名那一层**（`缘/….model3.json`），这是识别模型的依据，别把中间那层压掉。
- 模型**目录名即显示名**，在应用里改名会真的重命名文件夹。
