## 随手记

- zip 的**根目录就是模型名那一层**（`伊蕾娜·默认/….model3.json`），这是识别模型的依据，别把中间那层压掉。
- 模型**目录名即显示名**，在应用里改名会真的重命名文件夹。
- 这个模型随 APK 走；电脑版 fresh clone 不带模型，所以这里也放了一份单独的 zip。
