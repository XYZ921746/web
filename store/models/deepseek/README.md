# deepseek

随 ElainaChat Mod 一并分发的内置 Live2D 模型（Cubism 3），DeepSeek 鲸鱼娘。由**两位作者**共同完成。

| 安装 | 下载模型区的 zip，在应用里「设置 → Live2D 模型 → 上传新模型」选中它即可（不用解压） |

## 随手记

- 软件里对应的**内置人设已移除**，但那只是角色卡；模型本身照常可用，装进视频通话里选它就行。
- zip 的**根目录就是模型名那一层**，中间那层别压掉。
- 模型**目录名即显示名**，在应用里改名会真的重命名文件夹。
