怎么安装

下载 zip 后不要解压，按下面任一方式装进去。

应用内上传（推荐，手机也能用）

  • 下载需要的 .zip
  • 打开程序 → 设置 → 插件 → 上传安装 → 选中那个 zip
  • 在列表里打开对应的开关

丢进目录（仅电脑版）

  • 把 zip 直接放进 mods/ 目录
  • 在 设置 → 插件 点「重新扫描」
  • 服务端会自动解压，不用重启

安装完的 zip 会被自动清理 —— 所以「删掉插件目录」就是有效的卸载方式，不会被重新装回来。

Live2D 模型不在插件商店里：它们是二进制资源，走 模型区 下载。
