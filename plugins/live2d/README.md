# Live2D 视频通话

全屏视频通话界面：Live2D 模型 + 口型同步 + AI 表情/动作/情绪驱动。

## 依赖

**需要先启用「Live2D 引擎与模型」**（`live2d-models`）。它提供：

- 运行引擎（Cubism Core / PIXI / pixi-live2d-display，合计 787 KB，**按需加载**）
- 模型清单与模型文件

缺这个前置时本插件会被**拒绝加载**（不是带病运行），设置 → 插件 里会标明原因。

## 怎么用

1. 设置 → 插件 → 打开「Live2D 引擎与模型」与「Live2D 视频通话」两个开关
2. 设置 → Live2D → 上传模型（`.zip`，Cubism 3/4），或直接用内置模型
3. 点顶部栏的「视频通话」按钮

## 设置项

| 位置 | 说明 |
| --- | --- |
| 设置 → Live2D | 模型列表 / 上传 / 重命名 / 删除 |
| 设置 → Live2D → 鼠标跟随 | 头部与视线跟随鼠标；幅度可调（滑块 0-10，数字框最大 100） |
| 设置 → Live2D → 背景设置 | 预设渐变 / 纯色 / 自定义颜色 / 图片 |

## AI 能驱动它做什么

模型回复里带这些标签即可（标签不会显示给用户）：

```text
[情绪:开心]  [表情:脸红]  [动作:挥手]  [位置:left]  [大小:大]  [背景:星空]
[操作:打开视频通话]  [操作:结束通话]  [操作:静音]  [操作:隐藏水印]
```

可用表情/动作由**当前模型**决定，系统提示词会自动注入该模型真实的表情与动作文件名，
所以换任何模型都能自适应。

## 技术说明（给改代码的人）

| 文件 | 作用 |
| --- | --- |
| `index.js` | 通话实现主体（渲染、口型、表情/动作驱动、模型尺寸调整） |
| `settings-panel.js` | 设置面板的行为（模型管理、背景、鼠标跟随） |
| `panel.html` | 设置面板的结构 |
| `register.js` | 装配：注册 `settings.tabs` 与 `header.actions` 两个插槽 |
| `style.css` | 面板样式 |

几个容易踩的点：

- **注册点只有一个**（`register.js`）。`index.js` / `settings-panel.js` 只暴露
  `window.__live2dInitXxx` 函数 —— 两个文件都调 `ElainaMods.register` 的话，
  后注册的会**覆盖**前一个，表现为"插件 ready 但只有一半装配生效"。
- `manifest.scripts` 列出的文件**先**注入，`entry` **最后**注入 ——
  装配文件要调用其它文件定义的东西，顺序反了会拿到 undefined。
- 引擎**懒加载**：`window.ElainaLive2DModels.ensureEngine()` 在真正打开通话时才注入
  那三个库（不装 Live2D 的用户不必为 787 KB 付代价）。
- 实现主体仍挂 `window.Live2DCall` —— 宿主有约 30 处 `window.Live2DCall?.xxx`
  调用点（设置、语音口型、Agent、提示词），保留这个名字它们就一行都不用改。

## 已知限制

- 部分模型没有绑定眉毛 / 微笑参数，情绪里的"皱眉""挑眉"在那类模型上无法表达
- 参数"存在"与"绑定"无法在运行时便宜地探测，靠候选名 + 关键字兜底
- 手机（APK）端未实测
