# Galgame 界面

全屏沉浸式剧情界面：场景背景 + 立绘 + 打字机对话框，内置 **「情景演绎」**（全屏 Live2D 互动）。
与主界面**共用同一份对话数据**。

> 原独立的「Live2D 视频通话」插件已并入本包（2026-10）：两者是同一件事的两种呈现，
> 拆成两个包时要开两个开关、市场里还要装两次。现在**一个包、一个开关**，
> 主界面顶栏的入口叫「情景演绎」。

## 依赖

需要先启用三个前置（缺任一个本插件会被**拒绝加载**，设置 → 插件 里会标明原因）：

| 前置 | 提供什么 |
| --- | --- |
| **伊蕾娜立绘与情绪**（`elaina-avatar`） | 立绘与情绪识别 |
| **场景背景图**（`scene-backgrounds`） | 31 张场景背景 |
| **Live2D 引擎与模型**（`live2d-models`） | 情景演绎用的运行引擎、模型清单与模型管理界面 |

> 这些资源**不在本包里**（2026-10 搬到独立资源包）—— 用它们的不只是剧情界面。
> 留在本包里会变成"想要背景就得启用剧情界面"，而且卸载时会一起带走。

## 怎么用

1. 设置 → 插件 → 打开「Galgame 界面」（上面三个前置会在启用时被自动拉起来）
2. 主界面进入全屏剧情模式（右上角可退出）
3. 想用情景演绎：点**主页右上角**的「情景演绎」按钮（不必先打开剧情界面）
4. 第一次用情景演绎前，先到插件卡片上的齿轮 →「情景演绎」里选模型；上传 / 重命名 / 删除在「Live2D 引擎与模型」的设置里

## 特性

- **31 张场景背景**（来自 `scene-backgrounds`），按对话内容自动切换
- 打字机对话框、粒子特效
- 与主界面共用对话数据 —— 在剧情界面发的消息，回到主界面照样在
- 立绘随 AI 回复的情绪自动切换（走 `elaina-avatar` 的情绪词表）
- **情景演绎**：全屏 Live2D 模型、口型同步、AI 表情/动作/情绪驱动、鼠标跟随、可调大小与位置

## 情景演绎：AI 能驱动它做什么

模型回复里带这些标签即可（标签不会显示给用户）：

```text
[情绪:开心]  [表情:脸红]  [动作:挥手]  [位置:left]  [大小:大]  [背景:深蓝]
[操作:打开视频通话]  [操作:结束通话]  [操作:静音]  [操作:隐藏水印]
```

可用表情/动作由**当前模型**决定，系统提示词会自动注入该模型真实的表情与动作文件名，
所以换任何模型都能自适应。

## 情景演绎设置

| 位置 | 说明 |
| --- | --- |
| 插件卡片 → 齿轮 →「情景演绎」 | 用哪个模型 / 背景 / 鼠标跟随 / 打开测试 |
| 情景演绎 → 模型 | 选择当前模型；上传 / 重命名 / 删除在「Live2D 引擎与模型」的设置里 |
| 情景演绎 → 鼠标跟随 | 头部与视线跟随鼠标；幅度可调（滑块 0-10，数字框最大 100） |
| 情景演绎 → 背景设置 | 上传图片 / 从场景背景图里挑 / 清除 |

## 技术说明

| 文件 | 作用 |
| --- | --- |
| `index.js` | 剧情界面（装配入口；同时把情景演绎挂起来） |
| `index-live2d.js` | 情景演绎实现主体（渲染、口型、表情/动作驱动、模型尺寸调整） |
| `register.js` | 情景演绎的装配（顶栏按钮 + 设置窗插槽），由 `index.js` 调用 |
| `settings-panel.js` / `panel.html` | 情景演绎设置面板的行为与结构 |
| `style.css` | 剧情界面 + 设置面板样式（随插件启用/停用） |

几个容易踩的点：

- **注册点只有一个**（`index.js`）。`index-live2d.js` / `settings-panel.js` 只暴露
  `window.__live2dInitXxx` 函数 —— 多调一次 `ElainaMods.register` 会**覆盖**主界面，
  表现为"插件 ready 但剧情界面没了"。
- `manifest.scripts` 列出的文件**先**注入，`entry` **最后**注入 ——
  装配文件要调用其它文件定义的东西，顺序反了会拿到 undefined。
- **提示词只有一段**：`host.setPromptHint` 在同一插件内是覆盖而不是拼接，
  所以场景说明与 Live2D 表现指南由 `index.js` 的 `syncSceneHint()` 合成一次注入。
- 背景图走 `host.require('scene-backgrounds')`、立绘走 `host.require('elaina-avatar')`、
  引擎与模型走 `host.require('live2d-models')` —— 都不自己拼图片/脚本路径，
  用户改了那些包的目录名也不会 404。
- 引擎**懒加载**：`window.ElainaLive2DModels.ensureEngine()` 在真正打开情景演绎时才注入
  那三个库（不用的用户不必为 787 KB 付代价）。
- 情景演绎的实现主体挂 `window.Live2DCall` —— 宿主有约 30 处 `window.Live2DCall?.xxx`
  调用点（语音口型、Agent 表情），保留这个名字它们就一行都不用改。
- 情景演绎的设置键统一在 `galgame.live2d.*` 下（原 `live2d.*` 会在加载时一次性迁移过来）。

## 已知限制

- 退出剧情界面时会把 mod 开关一起关掉（语义是"退出 = 停用这个插件"），
  情景演绎随之收起
- 背景是 `.jpg`，且清单（`scene-backgrounds/index.js` 的 `BGS`）需与图片文件一一对应
- 部分 Live2D 模型没有绑定眉毛 / 微笑参数，情绪里的"皱眉""挑眉"在那类模型上无法表达
- Live2D 在手机（APK）端未实测
