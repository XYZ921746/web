# Galgame 界面

全屏沉浸式剧情界面：场景背景 + 立绘 + 打字机对话框。与主界面**共用同一份对话数据**。

## 依赖

需要先启用两个前置（缺任一个本插件会被**拒绝加载**，设置 → 插件 里会标明原因）：

| 前置 | 提供什么 |
| --- | --- |
| **伊蕾娜立绘与情绪**（`elaina-avatar`） | 立绘与情绪识别 |
| **场景背景图**（`scene-backgrounds`） | 31 张场景背景 |

> 背景**不再住在 galgame 里**（2026-10 搬到独立的资源包）—— 因为用它的不只是剧情界面，
> 视频通话也要拿它们当背景。放在 galgame 里会变成"想要背景就得启用剧情界面"，
> 而且卸载 galgame 会把背景一起带走。

## 怎么用

1. 设置 → 插件 → 打开上面两个前置与「Galgame 界面」
2. 主界面出现全屏剧情模式入口（右上角可退出）

## 特性

- **31 张场景背景**（来自 `scene-backgrounds`），按对话内容自动切换
- 打字机对话框、粒子特效
- 与主界面共用对话数据 —— 在剧情界面发的消息，回到主界面照样在
- 立绘随 AI 回复的情绪自动切换（走 `elaina-avatar` 的情绪词表）

## 技术说明

- `index.js`：界面与渲染
- `style.css`：样式（随插件启用/停用）
- 背景图**不在本目录** —— 走 `host.require('scene-backgrounds')` 取，
  这样用户改了那个包的目录名也不会 404
- 立绘走 `host.require('elaina-avatar')`，同样不自己拼图片路径

它通过 `host.require('elaina-avatar')` 取立绘接口，而不是自己拼图片路径 ——
这样用户改了插件目录名也不会 404。

**提示词注入**走 `host.setPromptHint()`：插件可以往 system 提示词里追加内容，
影响模型行为（例如告诉 AI 当前处于剧情模式）。停用插件时这段提示词会被自动摘掉。

## 已知限制

- 退出时会把 mod 开关一起关掉（语义是"退出剧情模式 = 停用这个插件"）
- 背景是 `.jpg`，且清单（`scene-backgrounds/index.js` 的 `BGS`）需与图片文件一一对应；
  `check-scene-backgrounds.mjs` 会盯着这件事
