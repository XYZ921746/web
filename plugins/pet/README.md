# 桌宠

悬浮在桌面上的角色：立绘 + 聊天气泡，AI 回复时自动切换表情。

## 依赖

**需要先启用「伊蕾娜立绘与情绪」**（`elaina-avatar`）—— 立绘与情绪识别与 Galgame **共用同一份**。
缺这个前置时本插件会被**拒绝加载**。

## 怎么用

1. 设置 → 插件 → 打开「伊蕾娜立绘与情绪」与「桌宠」两个开关
2. 应用内右下角出现悬浮角色（可拖动）
3. 点拖动条上的「🖥 桌面」→ 角色浮到桌面上（效果见下，取决于你用的运行环境）

## 浮到桌面（电脑端）

- **桌面壳（ElainaChat.exe，WebView2）**：浮出为**真透明置顶桌宠**——桌面上只有人物立绘，
  周围完全透明、点击直接穿透到下层应用。这是推荐形态。
- **普通浏览器（Chrome / Edge 116+）**：浮出为**置顶小窗**（Document Picture-in-Picture）——
  永远盖在其它应用上面，但窗口背景是一块不透明色块（浏览器窗口做不到透明，这是浏览器的硬限制）。
- Firefox、无该 API 的环境：不显示「🖥 桌面」按钮，桌宠留在应用内浮层。
- 关掉桌面桌宠（菜单「收起」或关窗）＝收起桌宠并同步关闭插件开关，与应用内 ✕ 同语义。

## 桌面透明桌宠（壳内）的交互

- **按住人物拖动**＝移动位置（位置会记住，下次启动还在原地）
- **点一下人物**＝弹出菜单：💬 聊天、⚙️ 设置、⚡ 主动搭话（可开关）、✕ 收起桌宠
- **💬 聊天**：人物脚下出现输入框，Enter 或 ➤ 发送；AI 回复以气泡出现在**人物左上角**，并按设置朗读（TTS）
- **⚙️ 设置**：直接在桌宠窗内调频率与朗读，不打开主应用
- 人物周围的透明区域点击会**直接穿透**到下层应用，不会误触

## 主动搭话（随机截屏）

开启后，AI 会按频率**随机截取一张屏幕截图**，看看你在做什么，再自然地搭一句话。

- 频率：快（5 分钟以内）/ 中（30 分钟以内）/ 慢（1 小时以内）/ 自定义分钟数
- 实际时点在该时间窗的 30%~100% 之间随机，说完重新排，不机械
- 截图由本插件的服务端半边抓取（`POST /api/pet/screenshot`，PowerShell 抓主屏），**不落盘、不发网络**，只随对话发给你自己配置的 AI 供应商
- 需要电脑版服务端在运行；手机端没有截屏能力，开启后会提示并自动关回
